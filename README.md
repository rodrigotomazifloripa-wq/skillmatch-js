# SkillMatch JS

## Sobre o Projeto

O SkillMatch JS e um simulador de compatibilidade entre o perfil de um candidato e vagas de Front-End Junior.

O sistema compara as habilidades do candidato com os requisitos de cada vaga e exibe o percentual de compatibilidade, habilidades faltantes e recomendacoes de estudo.

## Como Executar

1. Abra o Google Chrome
2. Pressione F12 para abrir o DevTools
3. Va na aba Console
4. Copie o conteudo de skillmatch.js e cole no console
5. Pressione Enter
